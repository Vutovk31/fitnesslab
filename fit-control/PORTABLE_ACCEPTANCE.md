# Portable acceptance bundle
The bundle is a distribution of the existing browser acceptance runner, not an application release. Compile TypeScript using the pinned source and compiler (5.8.3), package dist/nutrition.js, dist/storage.js, tests/browser/index.html, storage.test.mjs, run.py, report_contract.py, tools/acceptance_bundle.py, preserving paths. Create manifest.json with schema_version=1, source_commit=<full Git commit>, sha256 mapping exactly those seven relative paths to file digests. Run python tools/acceptance_bundle.py from the extracted package. Requires Python 3, Playwright 1.57.0 and its authorized Chromium (or CHROMIUM_PATH pointing to an authorized installed Chromium). No Node or Git needed to run precompiled bundle. Do not disable sandbox or change managed policies. If prerequisites are missing, install them only with permission. Runner writes ACCEPTANCE_RESULT.json locally; review stdout/stderr before sharing because diagnostics may include local paths. No automatic upload. A PASS is not a production release and not a cryptographic attestation. Compare manifest with pinned source and review actual 14 named cases. Do not close P0-02B otherwise.
