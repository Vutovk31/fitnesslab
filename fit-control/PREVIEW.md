# FIT CONTROL preview
From fit-control: provision TypeScript 5.8.3, run npm test, then python preview/build.py FIT_CONTROL.html. The standalone HTML uses compiled canonical domain modules with data URL imports, no network dependencies. This is a synthetic preview and memory only; do not enter actual personal data. To run minimal DOM smoke, extract the module script from built HTML into standalone-script.mjs in fit-control and run node tests/dom-smoke.mjs. This is not browser E2E. No persistence or clipboard acceptance claimed. Export is manual; inspect the report before sharing.
